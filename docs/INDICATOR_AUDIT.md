# Аудит индикаторов FABLES Trading Lab (2026-11-05)

Цель: проверить, что графики, легенда, таблицы и API показывают одну и ту же серию данных ядра, и объяснить расхождения
с DexScreener. Инструменты: вкладка терминала **«Аудит индикаторов»**, `GET /api/audit/{tf}?mode=FORWARD|BACKTEST`,
`python -m tradinglab audit --tf 1h [--md FILE]`.

## 1. Методика каждого индикатора

| Индикатор | Формула ядра (`tradinglab/indicators.py`) | Данные | Свеча | Отличие от TradingView / DexScreener |
|---|---|---|---|---|
| RSI(14) | Wilder: RMA приростов/потерь, засев SMA первых 14 | close закрытых 1H/4H/1D свечей GeckoTerminal | последняя закрытая | нет (ta.rsi тоже Wilder/RMA с засевом SMA) |
| MACD(12,26,9) | EMA12 − EMA26, Signal = EMA9 от MACD, Hist = MACD − Signal; EMA засевается SMA первых n | close | последняя закрытая | Pine засевает EMA первым значением → разница затухает как (1−2/(n+1))^k |
| MFI(14) | typical price × volume, суммы положительного/отрицательного потока за 14 | H, L, C, объём USD | последняя закрытая | нет |
| CMF(20) | Σ((C−L)−(H−C))/(H−L)·V / ΣV за 20 | H, L, C, V | последняя закрытая | нет |
| OBV | Σ sign(ΔC)·V с нуля на первой свече | C, V | последняя закрытая | нет (начало отсчёта то же) |
| EMA 20/50 (1D: 10/20) | EMA, засев SMA | close | последняя закрытая | засев (см. MACD) |
| Bollinger(20, 2) | SMA20 ± 2·σ генеральной совокупности | close | последняя закрытая | нет (ta.stdev biased) |
| ATR(14) | RMA(TR), TR с 2-й свечи | H, L, C | последняя закрытая | Pine: TR первой свечи = H−L, старт на свечу раньше → затухает |
| ADX/DMI(14) | Wilder | H, L, C | последняя закрытая | нет |

Время свечи — **начало периода, UTC** (как GeckoTerminal). DexScreener подписывает ту же свечу началом периода в часовом поясе
браузера: свеча 17:00 UTC у пользователя в UTC+3 отображается как 20:00.

## 2. Единство серий
Один и тот же массив ядра (`Analysis.arr`) отдаётся в API (`series`), рисуется на графике, используется в легенде, подсказках и
таблице «Индикаторы» (значение последней закрытой свечи) и в решениях стратегий. Проверяется тестами:
`test_chart_series_are_exactly_core_arrays_and_hist_is_macd_minus_signal` (API = ядро), `test_table_values_equal_chart_series_last_closed`
(таблица = график = API), UI-тесты в Chromium (нарисованные данные = API, Hist = MACD − Signal в каждой точке).

## 4. Случай RSI: DexScreener 26.76 против нашего 29.8 (1H)
- Наши **29.84** — RSI закрытой свечи 2026-11-05 17:00 UTC (close 0.058018), совпадает с эталоном Pine до бита.
- **Формула одна**: «RSI (SMA 14)» в легенде DexScreener — это параметры индикатора TradingView, где SMA 14 — *скользящая средняя
  от RSI* (вторая линия), а сам RSI — Wilder/RMA. SMA-вариант RSI (Cutler) на этих данных дал бы ≈ 9.9, EMA-вариант ≈ 15.4 —
  ни один не близок к 26.76.
- **Главная причина — формирующаяся свеча**: DexScreener показывает RSI текущей (незакрытой) свечи, который меняется с ценой; мы на
  графике и в стратегиях — RSI закрытой. Теперь панель показывает оба значения: «закрытая» и «LIVE (формирующаяся)».
- **Вторая причина — разные свечи**: DexScreener строит свечи из своего индекса сделок, мы — из GeckoTerminal. Даже по нашим данным
  формирующаяся свеча дала бы RSI = 26.76 лишь при цене ≈ 0.05726, а её минимум по GeckoTerminal — 0.05753; значит, свечи
  DexScreener отличаются. Публичного API свечей DexScreener нет, поэтому эта часть сравнивается только по наблюдениям.
- GeckoTerminal задним числом закрытые свечи не правит: 376 свечей, записанных в 13:27, совпали с отдачей в 18:4x. Правки, если появятся,
  фиксируются (`candle_revisions`) и отмечаются в аудите.

## 5. Формирующаяся свеча (FORWARD / LIVE)
Строится сервером (`tradinglab/live/forming.py`) для 1H/4H/1D: open — open периода (GeckoTerminal), high/low — экстремумы с начала
периода (GeckoTerminal + все котировки пула), close — текущая проверенная котировка; обновляется каждые 5 с, полупрозрачная, с меткой
`FORMING`. Пока GeckoTerminal не отдал только что закрытый период, он показывается «закрыта · ждёт GT». Стратегии и Risk Monitor
формирующуюся свечу не используют (тест `test_forming_bar_is_display_only_and_never_reaches_strategies`). Линия `Live` удалена.
