## Что реализовано
| Модуль | Содержание |
|---|---|
| `tradinglab/candles.py` | только закрытые свечи (grace 180 c), дедупликация (первая запись не перезаписывается), конфликты, OHLC-валидация, пропуски без заполнения |
| `indicators.py` | EMA/SMA, RSI, MACD, ATR, ADX/DMI, Bollinger + ширина + %b, MFI, CMF, OBV, относительный объём; warmup → `None` |
| `structure.py` | подтверждённые pivots (`confirmed_idx`), HH/HL/LH/LL, BOS/CHoCH, liquidity sweep, EQH/EQL, FVG, S/R-кластеры, log-Fibonacci |
| `divergence.py` | regular/hidden bullish/bearish, двойные; координаты, расстояние, величина, момент подтверждения; порог шума |
| `analysis.py` | снимок состояния на баре i, статусы `OK`/`INSUFFICIENT_HISTORY`, режим TREND_UP/DOWN/RANGE/TRANSITION |
| `strategies.py` | S1 (1H sweep reversal), S2 (4H structure pullback), S3 (1D range breakout) v1.0.0; условия ✓/✗/не проверено, план, объяснение из условий |
| `execution.py` | buy 0,5% / sell 1,0% (измерено), x·y=k импакт на консервативной глубине, slippage, доп. slippage стопа, газ; квантование 18/6 знаков |
| `portfolio.py` | Decimal, FIFO-лоты, инварианты (нет отрицательного кеша, нет продажи отсутствующего, fill один раз) |
| `risk.py` | `risk-v1`: риск на сделку, доля капитала, лимит периода, kill switch по просадке, серия убытков, cooldown, аномалии, мин. R:R, размер |
| `engine.py` | автомат WARMUP/FLAT/ENTRY_PENDING/LONG/EXIT_PENDING/PAUSED/RISK_OFF/DATA_ERROR; исполнение по следующей цене, отмена входа при гэпе за стоп или ухудшении R:R |
| `store.py` | отдельная `trading_lab.db`, append-only триггеры, неизменяемый эксперимент, атомарная запись бара + состояния, запрет ретро-записей в FORWARD |
| `backtest.py`, `performance.py`, `__main__.py` | backtest с общим стартом и B&H по той же модели; метрики ТЗ §10; офлайн-CLI |

## Тесты
`python -m pytest tests` → **209 passed** (166 прежних + 43 новых: `test_tradinglab_core.py` 20, `test_tradinglab_engine.py` 23).
Покрыто: ручные эталоны индикаторов; warmup; **расчёт на обрезанном ряду = расчёт на полном** (нет look-ahead/перерисовки);
исполнение по open следующей свечи; повтор бара — no-op; двойная запись → откат; отрицательный кеш и продажа отсутствующего
запрещены; издержки = убыток круга по одной цене; FIFO при частичных продажах; стоп по гэпу хуже уровня; стоп раньше цели;
trailing со следующего бара; time stop; блокировка при пропуске данных; R:R-фильтр; размер по риску; kill switch;
рестарт → идентичное состояние и баланс из журнала; append-only; BACKTEST ≠ FORWARD; изоляция трёх портфелей; HTF только закрытые.

Найден и исправлен тестом дефект: «пыль» 1e-38 FABLES после частичных продаж → квантование как в чейне.

- Forward-режим: сервис живых данных (`datasvc`) и forward-модель импакта по активной ликвидности (StateView) **не реализованы** —
  нужны разрешения (§10 документа этапа A).
- Рыночный контекст (ETH/BTC) и фундаментальные фильтры подключены как условия, но без данных → «не проверено» (не блокируют S2/S3).
- Order blocks не формализованы (v1 их не использует).
- Модуль эффективности сигналов (ТЗ §11) — только первичные данные (условия каждого решения, MFE/MAE); аналитики ещё нет.
- Комиссия hook (`feeKeeper:true`) может измениться — нужен монитор по Swap-событиям.
- Панель (этап D) не начата.
