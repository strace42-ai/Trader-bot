## 2. Этап D — веб-терминал

**Стек**: FastAPI + uvicorn (сервер), vanilla JS без сборки (как в Defi-Alpha — проще сопровождать на Windows),
TradingView Lightweight Charts 5.2.1 (локально в `web/static/vendor`, работает без интернета; панели осцилляторов — нативные panes v5).

| Компонент | Файл |
|---|---|
| Сервер, API, состояние лаборатории | `tradinglab/web/app.py` |
| Преобразование объектов ядра в JSON, интерпретации индикаторов | `tradinglab/web/views.py` |
| START/PAUSE/RESUME/STOP, обработка новых свечей FORWARD | `tradinglab/forward.py` |
| Набор записанных данных + манифест | `tradinglab/dataset.py`, `datasets/fables_2026-11-05/` |
| Миграция схемы v2: журнал `controls` (append-only) | `tradinglab/store.py` |
| Страницы | `web/static/index.html`, `performance.html`, `app.js`, `perf.js`, `common.js`, `style.css` |
| Запуск | `start.bat` (Windows), `start.sh`, `python -m tradinglab serve` |

API: `GET /api/overview`, `GET /api/terminal/{1h|4h|1d}?mode=BACKTEST|FORWARD`, `GET /api/performance`,
`GET /api/forward`, `POST /api/forward/{start|pause|resume|stop}` (недопустимый переход → 409).

**Связь с ядром.** Бэктест пересчитывается при запуске сервера тем же кодом; при первом запуске журнал сохраняется в
`data/trading_lab.db`, при следующих — пересчёт сверяется с журналом (`VERIFIED`/`MISMATCH` во вкладке «Диагностика»).
Свечи, индикаторы, решения, условия, операции, сделки и метрики в панели — объекты ядра; ничего не генерируется на клиенте.

**FORWARD.** До START — `NOT STARTED`, данных портфелей нет. START создаёт эксперимент с неизменяемым моментом начала.
Источник живых данных не подключён (`NOT CONNECTED` с причиной): сервер не делает сетевых запросов (это проверяет тест)
и не запускает фоновых процессов, поэтому после START новых свечей и сделок нет — и панель это явно показывает.
