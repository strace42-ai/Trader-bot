# Первый запуск на Windows — FORWARD paper trading

Только виртуальная торговля: реальных средств, ключей и транзакций нет.

## 1. Установка (один раз)
1. Установите **Python 3.11 или новее** с <https://www.python.org/downloads/>. В установщике отметьте **«Add python.exe to PATH»**.
2. Получите код:
   - через Git (рекомендуется, удобно обновлять):
     ```bat
     git clone https://github.com/strace42-ai/Trader-bot.git C:\TraderBot
     cd C:\TraderBot
     ```
     До объединения PR используйте ветку: `git clone -b claude/stage-e-forward-live https://github.com/strace42-ai/Trader-bot.git C:\TraderBot`
   - или GitHub → Code → Download ZIP и распакуйте в `C:\TraderBot` (путь без особых символов).

## 2. Диагностика до START
Дважды щёлкните **`diagnose.bat`** (или в консоли `cd C:\TraderBot` и `diagnose.bat`). Он:
- проверяет версию Python, создаёт `.venv` и ставит зависимости (журнал установки — `data\logs\install.log`);
- проверяет версии пакетов, запись в папку данных, базу `data\trading_lab.db` (схема, целостность);
- выполняет **самопроверку рестарта** (START → PAUSE → перезапуск → статус и журнал восстановлены) во временной базе;
- опрашивает **все живые источники** (GeckoTerminal, DexScreener, Robinhood RPC/StateView и тики пула, CoinGecko) и выполняет preflight;
- сохраняет отчёт `data\logs\diagnostics-ДАТА.txt` — его можно передать для разбора проблем (токен управления в отчёт не попадает).

Итог должен быть «**ВСЁ В ПОРЯДКЕ — можно нажимать START**». Предупреждения о незапущенных боте и панели при диагностике нормальны.

## 3. Запуск
Дважды щёлкните **`start.bat`**. В окне появится:
```
FABLES Trading Lab — PAPER (виртуальная торговля, реальных транзакций нет)
Фоновый бот: запущен ...
Панель: http://127.0.0.1:8770/
```
Браузер откроет панель. Первые ~30–60 с бот загружает историю свечей — preflight до этого не пройдёт.

## 4. START
Нажмите **START** в верхней панели. Сначала выполняется проверка готовности; если что-то не готово, START не отправляется и
показывается причина. После подтверждения создаётся эксперимент `FW-…` с неизменяемым моментом начала.

Что видно сразу:
- верхняя панель: живая цена, «Котировка: ПРОВЕРЕНА», время последнего успешного получения данных у каждого источника, heartbeat бота;
- у каждого трейдера: последнее решение, время последней проверки стопа и уровень защиты позиции, отсчёт до закрытия свечи.
  Первые решения появятся после ближайшего закрытия: 1H — в начале следующего часа (+≈3 мин), 4H — в 00/04/08/12/16/20 UTC, 1D — в 00:00 UTC (1D — WARMUP до 30 дневных свечей).

## 5. Повседневная работа
- Закрытие вкладки браузера бота **не** останавливает. Панель можно открыть снова: <http://127.0.0.1:8770/>.
- Бот работает, пока открыто окно `start.bat`. Закрытие окна/выключение ПК — пауза наблюдения; после запуска эксперимент продолжается,
  пропущенные свечи идут только в историю (`SKIPPED`), сделок задним числом нет.
- Отключите спящий режим при питании от сети: «Параметры → Система → Питание и спящий режим → Никогда».
- По желанию: `autostart_enable.bat` — запуск при входе в Windows (ярлык в «Автозагрузке», отключается `autostart_disable.bat`).

## 6. Восстановление после перезапуска
При каждом запуске бот сверяет кеш и количество FABLES каждого трейдера с журналом операций. При расхождении в панели появляется
красное предупреждение «Целостность состояния нарушена», START блокируется — запустите `diagnose.bat` и передайте отчёт.

## 7. Журналы для диагностики
| Файл | Что внутри |
|---|---|
| `data\logs\tradinglab.log` | все ошибки бота, API и источников с трассировкой (ротация 5 × 5 МБ) |
| `data\logs\install.log` | вывод pip при установке зависимостей |
| `data\logs\diagnostics-*.txt` | отчёт `diagnose.bat` |
| `data\trading_lab.db` | вся история: свечи, котировки, решения, операции, команды (не удаляйте во время эксперимента) |

## 8. Остановка эксперимента
**STOP** завершает эксперимент без автоматической продажи; позиции остаются и оцениваются по рынку. Продать вручную —
**CLOSE POSITION** (у трейдера) или **EMERGENCY EXIT** (все позиции). Новый START создаёт новый эксперимент, старый сохраняется.
